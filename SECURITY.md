# Security policy / 安全政策

Please **do not** report security problems in public issues.
請**不要**在公開的 issue 回報安全問題。

Report privately through GitHub: **Security → Report a vulnerability** on this repository
(private vulnerability reporting). We will reply as soon as we can.
請用本 repo 的 **Security → Report a vulnerability**（私下回報）。

Useful details / 請附上：
- Version and platform / 版本與平台
- Steps to reproduce / 重現步驟
- What an attacker could do / 可能的影響

Scope / 範圍：this desktop app, its local server (`local-server/`) and build scripts.
Never include real API keys in a report / 回報內容請不要附真的 API 金鑰。
